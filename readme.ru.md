# Mist_os(fakeos) 
Язык: [English](README.md) | [Руский](README.ru.md)



Просто фейковая ос созданая с помощью customtkinter и python


<img width="640" height="480" alt="image" src="https://github.com/user-attachments/assets/37935e5c-e25e-4a5d-ac3a-0ee87477710e" />


Чтобы использовать ОС нужно установить зависимости вводя ети команды в командную строку


customtkinter:
```bash
pip install customtkinter
```
PIL:
```bash
pip install pillow
```
После этого можно скачать ОС
версия alpha 1.3
